Таны C Shard програмууд `mem[0x4000 + ...]` руу бичиж аль хэдийн зурж чаддаг ч програм бүр пикселийн хаяг ба бит mask-ыг дахин дахин бодох болно. **[[Үйлдлийн систем|operating-system]]** бол бүх програмын хуваалцдаг код. Том системүүд олон програмыг зэрэг ажиллуулж, файл хадгалдаг. Манайх аль алиныг нь хийхгүй: энэ нь дэлгэц, бичвэр, гар, цаг ба санамсаргүй тоонд зориулсан, програм бүрийн өмнө тавигддаг C Shard функцуудын сан. Та үүнийг өөрийн зохиосон хэлээрээ өөрөө бичнэ.

## Бидний хийсэн сонголтууд

| Асуулт | Бидний сонголт | Яагаад |
|---|---|---|
| Цаг хэмжих | 0x6001 хаяг дахь frame тоолуур, секундэд 60 | загварчлал хэр хурдан байхаас үл хамааран тоглоом ижил хурдтай явна |
| Санамсаргүй тоо | OS-д програмаар бичсэн генератор | шинэ техник хангамж хэрэггүй, "санамсаргүй" тоо үнэндээ хэрхэн гардгийг харна |
| Гарын код | ASCII, мөн Enter 13, Backspace 8, Escape 27, сумнууд 128–131 | нэг байтад багтана, бүх жишээ аль хэдийн ашигладаг |
| OS-ыг ашиглах | C Shard програм бүрийн өмнө тавигдана | хэл өөрчлөгдөхгүй; OS-ын нэрс зүгээр л эзлэгдсэн |

Timer бол шинэ техник хангамж: memory map одоо 0x6001 хаягийг 0x6000 дахь гарын хажууд `timer` оролт руу илгээнэ. Хэрэв та memory map эсвэл компьютерийг өмнө нь бүтээсэн бол тэдгээр түвшнийг дахин нээж, шинэ оролтыг холбоорой. Функцуудын бүтэн жагсаалт нь `docs/OS.md`.

## Пиксел бол бит

Дэлгэц 768 үг, мөр бүрд 8, пиксел бүр нэг бит. (x, y) пикселийг асаахын тулд `plot` түүний үгийг `0x4000 + 8y + x / 16`-д олж, зөв байранд ганц 1-тэй **[[bit mask|bit-mask]]** хийнэ: `0x8000 >> (x % 16)`, учир нь хамгийн зүүн пиксел нь хамгийн өндөр бит. Mask-тай OR пикселийг асааж, түүний урвуутай AND унтраана. Үгийн бусад пиксел хэвээр үлдэнэ.

Дүүргэсэн тэгш өнцөгт пиксел бүрд `plot`-ыг дуудаж болох ч тоглоом их зүйлийг дахин зурдаг. `fill_rect` нэг удаад нэг үгээр ажилладаг: мөр бүрд дараагийн үгийн хил хүртэлх пикселүүдийг хэд хэдэн 1-тэй нэг mask-аар хамардаг тул бүхэл үг арван зургаагийн оронд нэг унших, нэг бичихэд л зарцуулна. C Shard-д үгийн зүүнээс `bit` пикселээс эхэлсэн n ширхэг 1 нь `(-1 << (16 - n)) >> bit`.

## Тооноос бүтсэн фонт

Бичвэр бичихийн тулд OS-д үсэг бүрийн зураг хэрэгтэй. Манайх тэмдэгт бүрд 3 × 5 пикселтэй, энэ төсөлд зориулж зурсан **[[bitmap font|bitmap-font]]**. Арван таван пиксел нэг үгэнд багтдаг тул хоосон зайнаас `_` хүртэлх бүх фонт 64 тоо. Тэмдэгтүүд 4 × 6 пикселийн нүдэнд байрлах бөгөөд үсэг, мөрийн хооронд зай үлдээх тул дэлгэцэд 32 багана, 16 мөр бичвэр багтана.

## Товч ба цаг

`key()` 0x6000 дахь гарын үгийг уншина. `wait_key()` товч доошоо, дараа нь дахин дээшээ болохыг хүлээдэг тул нэг дарлага хэр удаан барьсан ч нэг удаа тоологдоно. `ticks()` 0x6001 дахь frame тоолуурыг уншиж, `wait(n)` дахин n frame өнгөртөл давтана. Тоолуур төв процессорын гаднаас ирдэг тул унаж буй Tetris-ийн хэсэг удаан, хурдан тохиргоонд ижил хурдтай хөдөлнө.

## Томъёоноос гарах санамсаргүй тоо

Хэлсэн ёсоор яг хийдэг компьютер шоо хаяж чадахгүй. Харин санамсаргүй мэт харагдах дараалал бодож чадна: **[[pseudo-random|pseudo-random]]** тоо. Манайх xorshift генератор ашигладаг: тоог өөрийнх нь шилжүүлсэн хуулбаруудтай нийлүүлнэ, `s ^ (s << 7)`, дараа нь `s ^ (s >> 9)`, дараа нь `s ^ (s << 8)`. Эдгээр гурван шилжилтээр дараалал давтагдахаасаа өмнө 16 битийн тэг биш бүх 65,535 утгаар дамжина; репозиторийн нэг шалгалт алхам бүрийг шалгадаг.

Ижил эхлэх утга буюу **[[seed|random-seed]]** үргэлж ижил дараалал өгнө. Тоглоом бүрийг өөр болгохын тулд OS анх товч дарагдахад timer-ээс дахин seed авна. Ингэснээр тоглогч товч дарахаасаа өмнө хэр удаан хүлээх нь тоглоомыг шийдэх бөгөөд секундийн жаранны нэгийн ижил тоог санаатайгаар хоёр удаа хүлээж чадах хүн үгүй.

## Хаанаас гаралтай вэ

Эртний компьютерууд нэг ажлыг ажиллуулаад дараагийнхыг оператор ачаалахыг хүлээдэг байв. 1956 онд General Motors Research-ийн Роберт Патрик ба North American Aviation-ий Оуэн Мок IBM 704-д зориулж GM-NAA I/O-г бичсэн. Үүнийг тэр машины анхны үйлдлийн систем гэж тодорхойлдог бөгөөд гол ажил нь одоогийн програм дуусахад дараагийнхыг автоматаар эхлүүлэх байв[@gm-naa-io]. Xorshift генераторуудыг 2003 онд Жорж Марсалья "simple, extremely fast" санамсаргүй тоо үүсгэгч гэж тодорхойлсон[@marsaglia-xorshift]; манай OS-ын ашигладаг гурван шилжилт бол тэр гэр бүлийн 16 битийн жижиг гишүүн.

## Юу бүтээв, юу сурав

**Юу бүтээв:** C Shard дээрх үйлдлийн систем: пиксел, тэгш өнцөгт, фонт, бичвэр ба тоо, гар, timer ба санамсаргүй тоо; мөн компьютерийн тань memory map дахь timer төхөөрөмж.

**Юу сурав:**

- Зурах нь бит хадгалах: хаяг үгийг олж, mask түүн доторх пикселүүдийг сонгоно.
- Нэг удаад нэг үгээр ажиллах нь нэг удаад нэг пикселээс 16 хүртэл дахин хурдан.
- Фонт бол өгөгдөл: тэмдэгт бүр тоо хэлбэрээр хадгалсан жижиг зураг.
- Цаг төв процессорын гаднаас ирдэг тул програм аль ч машин дээр ижил хурдтай явна.
- Компьютерийн санамсаргүй тоо томъёоноос гардаг; seed дарааллыг шийднэ.

**Дараа нь:** 9-р бүлэгт та транзистороос бүтээсэн компьютер дээрээ, өөрийн OS дээр, C Shard-аар Tetris бичнэ.
