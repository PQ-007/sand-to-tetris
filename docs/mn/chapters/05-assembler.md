4-р бүлэгт програм бол тоонуудын жагсаалт байсан: `0x4405, 0x0ca0, 0xcbfe`. Төв процессор тань үүнд сэтгэл хангалуун, харин өөр хэн ч биш. Хүмүүс оронд нь заавар, регистр, програмын байруудад нэр өгдөг **[[ассемблер хэлээр|assembly-language]]** бичдэг бөгөөд **[[ассемблер|assembler]]** гэдэг програм үүнийг **[[машины код|machine-code]]** болгон хөрвүүлдэг. Энэ бүлэгт та компьютерийнхээ програмуудыг бичих хэлийг сурч, дараа нь ассемблерийг өөрөө бичнэ.

## Нэрээс тоо руу

Ассемблер ид шид биш бөгөөд хөрвүүлж буй төв процессор дээрээ ажилладаггүй. Энэ бол бичвэр уншиж, тоо бичдэг энгийн програм. Нэг мөрийн хувьд тэр бичвэрийг хэсэг болгон хувааж, аль заавар болохыг олж, хэсгүүдийг `docs/ISA.md`-ийн битийн талбаруудад багцална: 15–13-р битэд бүлгийн дугаар, дараа нь регистрүүд, дараа нь тогтмол эсвэл offset. 16 битийн үг бүр ямар нэг заавар тул disassembler (урвуу хөрвүүлэгч) үгийг үргэлж буцааж уншиж чадна. Ассемблер ба disassembler бүх 65,536 үг дээр тохирдог; энэ бол жишиг ассемблерийн шалгалтуудын нэг.

## Хэл

Мөр нь хамгийн ихдээ гурван хэсэгтэй, бүгд сонголттой: **[[label]]**, заавар, `;`-ийн дараах тайлбар.

```
loop:   ADD  r0, r0, r1    ; total = total + counter
```

- Label ба тогтмолын **нэр** нь үсэг, цифр, `_`-аас тогтох бөгөөд том жижиг үсэг ялгаатай. Зааврын нэр ба регистрүүдийг (`r0`–`r7`) ямар ч үсгээр бичиж болно.
- **Тоо** нь аравтын (`42`, `-5`), арван зургаатын (`0x4000`), хоёртын (`0b1111_0000`, хүсвэл цифрүүдийн хооронд `_`) эсвэл тэмдэгт (`'A'` нь 65) байж болно.
- **Санах ой**-г `[r1 + 2]`, offset нь 0 бол `[r1]` гэж бичнэ.
- **Үсрэлт** label-ийг заах бөгөөд ассемблер хэр хол байгааг тооцно. Тоо бол зай өөрөө: `JMP 0` өөр рүүгээ үсэрнэ.

### Товчлол ба directive

**[[Pseudo-instruction|pseudo-instruction]]** гэдэг нь ассемблерийн ойлгодог ч төв процессорт байхгүй нэр. Энэ нь нэг эсвэл хэд хэдэн жинхэнэ заавар болно:

| Та бичнэ | Ассемблер гаргана |
|---|---|
| `SET16 r1, 0x4000` | `SET r1, 0` ба `SETH r1, 0x40` (0-ээс 255 хүртэлх утгад зөвхөн `SET`) |
| `INC r1` · `DEC r1` | `ADDI r1, 1` · `SUBI r1, 1` |
| `HALT` | `JMP 0`: өөр рүүгээ үүрд үсэрнэ |
| `NOP` | `JMP 1`: юуг ч өөрчлөхгүйгээр дараагийн заавар |

**[[Directive|directive]]** цэгээр эхэлж, заавар болохын оронд ассемблертэй ярина. `.equ SCREEN 0x4000` тоонд нэр өгнө. `.data` өгөгдлийн хэсэг рүү шилжих бөгөөд тэнд `.word 1, 2, 3` тоонуудыг, `.space 8` 8 тэгийг тавина; `.code` буцааж шилжүүлнэ. Манай компьютер програмаа LOAD уншиж чадахгүй ROM-д хадгалдаг тул өгөгдөл RAM-д очно. Програм эхлэхээс өмнө **[[loader]]** өгөгдлийн хэсгийг RAM руу 0 хаягаас эхлэн хуулах бөгөөд өгөгдлийн label нь тэр RAM хаяг болно:

```
.data
shapes: .word 0x0F00, 0x4444     ; RAM[0] ба RAM[1]
.code
        SET16 r1, shapes         ; r1 = 0
        LOAD  r2, [r1 + 1]       ; r2 = 0x4444
```

## Ассемблер хэрхэн ажилладаг вэ

Жишиг ассемблер ба таных ижил байдлаар, дөрвөн үе шаттай бүтээгддэг. Үе шат бүр өмнөхийнхөө гаргасныг авна.

### 1. Tokenize

Мөрийг token болгон хэрчинэ: `loop:` бол label, `ADD` ба `r1` бол нэр, `0x10` бол тоо, `,` `[` `]` `+` бол цэг таслал. Хоосон зай ба тайлбар алга болно. Энд муу тэмдэгт эсвэл `12ab` шиг тоог олж мэднэ.

### 2. Parse

Token-уудыг мөр болгон унш: сонголттой label, дараа нь заавар эсвэл directive, дараа нь таслалаар тусгаарласан operand-ууд. `r0`–`r7` регистр болох бөгөөд бусад нэр хожмын хэрэгцээнд нэр хэвээр үлдэнэ. Энд дутуу таслал эсвэл `]`-ийг олж мэднэ.

### 3. Layout: эхний давталт

Энд нэг оньсого бий. `JNZ loop`-д ассемблер `loop` хаана байгааг мэдэх ёстой, гэтэл урагш үсрэлт доор л гарч ирэх label-ийг заасан байж болно. Тиймээс ассемблер програмыг бүтнээр нь хоёр удаа уншина. Эхний давталт мөр бүрд хаяг өгч, бүх нэрийг **[[symbol table|symbol-table]]**-д цуглуулна. Заавар бүр нэг үг, зөвхөн SET16-ийн хэмжээ утгаасаа хамаардаг тул эхний давталт үүнийг ч шийднэ. Ийм байдлаар ажилладаг ассемблерийг **[[two-pass assembler|two-pass-assembler]]** гэнэ.

### 4. Encode: хоёр дахь давталт

Одоо нэр бүр утгатай болсон тул мөр бүрийг үгс болгож болно: label-уудыг хайж, үсрэлтийн зайг тооцож, тоо бүр талбартаа багтаж байгааг шалгаж, битүүдийг багцална.

Сайн ассемблер анхны алдаан дээр зогсдоггүй: асуудалтай мөр бүрийг мэдээлж, юу буруу болохыг хэлж, мөрийг заана.

## Ассемблер хаанаас гаралтай вэ

Програмыг тоогоор бичих нь хэдхэн жил л үргэлжилсэн. 1947 онд Кэтлин Бут Беркбек дэх ARC2 компьютерт зааврыг хоёртын тооны оронд товч тэмдэгтээр бичдэг "contracted notation"-ийг тодорхойлсон; үүнийг ихэвчлэн анхны ассемблер хэл гэдэг ч энэ нэр хожим гарсан бөгөөд маргаантай[@booth-contracted-notation]. 1949 оны 5-р сард Дэвид Уийлер Кембрижийн EDSAC-д "initial orders"-ийг бичсэн: товч үсгэн нэрээр цаасан туузанд цоолсон програмыг уншиж санах ойд оруулдаг хэдэн арван үг. Үүнийг ихэвчлэн анхны ассемблер гэдэг, энэ нь бас маргаантай "анхны" тухай мэдэгдэл бөгөөд тэр 9-р сарын хоёр дахь хувилбар ачаалах явцдаа хаягуудыг ч тохируулдаг байв[@edsac-initial-orders]. Түүнээс хойшхи ассемблер бүр ижил ажил хийдэг: нэр оруулж, тоо гаргана.

## Програмуудаа ажиллуулах

**Машин** хуудсан дээр та програм бичиж, хөрвүүлж, ажиллуулж болно: таны зохиосон компьютерийн дэлгэц, гар, регистрүүд ба RAM дээр. Энэ нь суурилуулсан ассемблераар эхэлдэг; таны өөрийнх workshop-ийн бүх шалгалтыг давмагц оронд нь сонгож болох бөгөөд програмууд тань битүүд хүртэл таны бичсэн кодоор дамжина. Програмууд төв процессорын хурдан загвар дээр ажилладаг тул тоглоомд хангалттай хурдан.

## Юу бүтээв, юу сурав

**Юу бүтээв:** манай ассемблер хэлийг машины код ба өгөгдлийн дүрс болгодог, өөр өөрийн шалгалттай дөрвөн үе шаттай ассемблер, мөн компьютерийн тань дэлгэц, гар дээр ажилладаг програмууд.

**Юу сурав:**

- Ассемблер хэл заавар, регистр, хаягуудад нэр өгдөг; ассемблер бол түүнийг машины код болгон хөрвүүлдэг энгийн програм.
- Pseudo-instruction ба directive нь төв процессорыг өөрчлөхгүйгээр програмыг богино бичих боломж олгоно.
- Label-ийг тодорхойлохоос өмнө ашиглаж болох тул ассемблер хоёр давталт хийнэ: эхнийх нь symbol table-ийг бүтээж, хоёр дахь нь кодлоно.
- Програмд хэрэгтэй өгөгдөл өөрийн хэсэгт байрлах бөгөөд програм эхлэхээс өмнө loader үүнийг RAM руу хуулна.

**Дараа нь:** 6-р бүлэгт та ассемблер дээр виртуал машин бүтээнэ: програм нь регистрээр бодох шаардлагагүй stack machine.

</aside>
