C Shard бол хэлийг хийж болдог зүйл гэдгийг харуулахын тулд бидний хамтдаа зохиосон хэл: token, syntax tree, төрөл шалгагч, VM код. **C** бол хүмүүсийн өдөр бүр ашигладаг жинхэнэ хэл бөгөөд энэ машин дээр дунд нь VM-гүйгээр шууд ассемблер болж хөрвүүлэгдэнэ. Энэ хэсгийн Bitfall-аас бусад бүх тоглоом үүн дээр бичигдсэн.

## Шууд ассемблер руу

C Shard хөрвүүлэгч `s = s + i;`-г VM командууд болгож, translator команд бүрийг stack-д push, pop хийдэг хэдэн заавар болгоно: тэр ганц мөрөнд 14 заавар. C хөрвүүлэгч (`toolchain/c`, `s2t-c` crate) илэрхийллийг бодох зуураа утгуудыг регистрт байлгадаг тул `s += i;` 4 заавар болно:

```
LOAD  r0, [r6 + 1]   ; s
LOAD  r1, [r6 + 2]   ; i
ADD   r0, r0, r1
STORE r0, [r6 + 1]
```

Регистрүүдийг ингэж ашиглана: r0-оос r4 нь илэрхийлэл бодох зуур утгуудыг барина, **r5 үргэлж 0** (тэгэхээр RAM-ын эхэн дэх глобал хувьсагч ганц `LOAD r0, [r5 + n]`), r6 бол stack pointer, r7 буцах хаягийг хадгална. Функцийн локал хувьсагчид түүний frame-д `[r6 + n]`-д байна. Тогтмолоор үржүүлэх нь shift ба нэмэх болно; зөвхөн хоёр хувьсагчийг үржүүлэх, хуваах үед жижиг routine дуудна.

ISA-д overflow flag байхгүй тул хоёр тэмдэгтэй тоог харьцуулахад арга хэрэгтэй: хоёулангийнх нь тэмдгийн битийг эргүүлээд тэмдэггүйгээр харьцуулна. Энэ нь гурван нэмэлт заавар зарцуулдаг тул тоглоомууд хамгийн ачаалалтай давталтууддаа pointer эсвэл тэмдэггүй тоогоор тоолох нь элбэг.

## 16 битийн машин дээрх C

Бүх зүйл нэг 16 битийн үг: `char`, `short`, `int` ба pointer. `sizeof(char)` нь 1, `sizeof(int)` ч 1; C нь "байт"-ыг 16 бит байхыг зөвшөөрдөг. `float` байхгүй: тоглоомууд оронд нь **[[fixed point|fixed-point]]** ашигладаг, 16 юм уу 256-аар үржүүлсэн утгатай `int`, тэгэхээр бөмбөг frame бүрт 24 арван зургаагийн нэг буюу 1.5 пиксел явж чадна. `long` ч байхгүй. Struct, union, массив, pointer, функцийн pointer, `switch`, `goto`, preprocessor-ын `#define`, `#if` бүгд ажиллана.

## machine.h

`#include <machine.h>` нь C-ээр бичигдэж, таны програмтай хамт хөрвүүлэгддэг сан өгнө; дуудаагүй зүйл тань орхигдоно.

| Функц | Хийдэг зүйл |
|---|---|
| `clear()`, `plot(x, y, on)`, `fill_rect(x, y, w, h, on)`, `draw_line(…)` | пиксел, тэгш өнцөгт, шулуун |
| `draw_sprite(x, y, rows, h)` | 16 хүртэл пиксел өргөн зураг, мөр бүр нэг үг |
| `draw_text("HI", col, row)`, `draw_int(n, col, row)` | OS-ын 3 × 5 фонтоор бичвэр |
| `use_buffer()`, `show()` | дэлгэцийн хуулбар дээр зураад нэг дор харуулах |
| `key()`, `wait_key()`, `ticks()`, `next_frame()` | гар ба секундэд 60 тоолдог timer |
| `rand()`, `rand_below(n)`, `sin256(a)`, `isqrt(v)` | санамсаргүй тоо ба бага зэрэг математик |

Арилгаж, дахин зурах зуураа шууд дэлгэц дээр зурвал зураг анивчина. Хуулбар дээр зураад нэг дор харуулах нь **[[double buffering|double-buffering]]**; энд байгаа тоглоом бүр үүнийг хийдэг.

## Өөрийнхөө програмыг бич

Машин хуудсан дээр **C** болон "Бичвэр, товч ба шоо" жишээг сонгоод өөрчил. Хуудас таны програм ямар ассемблер болсныг одоо ажиллаж буй зааврыг ▶-ээр тэмдэглэн харуулж, алдаанууд таны C мөрүүдийг заана. `docs/C.md` хөрвүүлэгчийн хүлээн авдаг бүх зүйлийг жагсаана.
