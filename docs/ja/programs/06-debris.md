**Debris** は、漂う岩の原の中の 1 隻の船です。左と右で船を回し、上で噴射し、スペースで撃ちます。手を離しても船は漂い続けます。大きな岩を撃つと中くらいの岩二つに、中くらいの岩は小さな岩二つに割れ、小さな岩は消えます。原を片づけると、もっと大きな波が来ます。船から残機の表示まで、すべてが直線で描かれます。`games/debris.c`、約 260 行の C です。

## 角度と向き

船の角度は 0 から 255 の数で、1 段階が 1 回転の 256 分の 1 なので、255 と AND を取れば自然に一周します。`machine.h` の `cos256(a)` と `sin256(a)` は、4 分の 1 回転分の 65 個の数の表から、コサインとサインの 256 倍を返します。噴射は、左右の速さに `cos256(angle) / 32` を、上下の速さに `sin256(angle) / 32` を加えます。

## 漂いと抵抗

位置と速さは 16 分の 1 ピクセル単位の **[[固定小数点|fixed-point]]** です。毎フレーム、どの速さも自分の 32 分の 1 を失う(`vx -= vx / 32`)ので、船は止まるのではなく穏やかに減速し、速さは 1 フレーム 2.5 ピクセルで頭打ちになります。どの端から出たものも反対側から戻ってきます。原は一周つながっているのです。

## でこぼこの岩

岩は、中心、速さ、大きさ、そして八つの角です。作られるとき、各角は岩の半径から少しランダムに引いた距離で、八つの方向のどれかに置かれるので、同じ形の岩は二つとありません。描くのは `draw_line` の 8 回の呼び出しで、`draw_line` はブレゼンハムの方法を使います。長いほうの向きに 1 ピクセルずつ進み、誤差を積算しながら、短いほうの向きにいつ進むかを決めるのです。

## 岩に当てる

弾が岩の半径の内側に入れば当たりです。dx² + dy² ≤ r² のときです。2 乗は掛け算で、このマシンはそれをシフトと足し算のルーチンで行うので、ゲームはまず安い方法で、dx か dy のどちらか一方だけで r より大きいかを調べ、弾が近いときだけ掛け算をします。

## 書き換えてみよう

- 船にブレーキを付ける。あるいは、ランダムな場所へ移るハイパースペースのジャンプを付ける。
- 岩が三つに割れるようにする。
- 岩どうしが跳ね返り合うようにする。
