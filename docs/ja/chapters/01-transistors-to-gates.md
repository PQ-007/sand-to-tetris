第 0 章では、[[MOSFET|mosfet]] が電圧で制御するスイッチだと学びました。この章では、そのスイッチを配線して **[[論理ゲート|logic-gate]]** を作ります。この先のすべてのレイヤーの材料になる小さな回路です。三つのゲートを自分で作り、それぞれの **[[真理値表|truth-table]]** で確かめます。合格したゲートは一つ一つ、あとで使える部品になります。

## スイッチは計算できる

コンピュータを可能にする考え方はこうです。1937 年、クロード・シャノンは、スイッチの回路がブール代数に従うことを示しました[@shannon]。

- **直列**(一つずつ順に)につないだ二つのスイッチ:A **かつ** B が閉じているときだけ電流が通ります。
- **並列**(横に並べて)につないだ二つのスイッチ:A **または** B が閉じていれば電流が通ります。

試してみましょう。スイッチの一つ一つがビット(閉=1、開=0)で、ランプが出力です。

<switch-network></switch-network>

つまり、**[[直列と並列|series-and-parallel]]** のスイッチは AND と OR を計算します。トランジスタは別の**電圧**で切り替わるスイッチなので、あるトランジスタの出力で次のトランジスタのゲートを動かせます。それをつなげていけば、どんなものでも計算できます。

## 二つのスイッチ

トランジスタは 2 種類あります(仕組みは第 0 章を参照)。

- **[[NMOS|nmos]]**:ゲートが **1** のときオン(導通)。
- **[[PMOS|pmos]]**:ゲートが **0** のときオン。

エディタでは、トランジスタにはそれぞれ三つのピンがあります。**gate**(制御)と、チャネルの両端である **source** と **drain** です。トランジスタがオンのときは source と drain がつながり、オフのときはつながりません。エディタは作業中、トランジスタごとに「オン」か「オフ」を表示します。

二つの電源レールもあります。常に 1 の **VDD** と、常に 0 の **GND**(グラウンド)です。どの出力も、最終的にはどちらかにつながっていなければなりません。

<details class="deeper">
<summary>さらに詳しく:なぜ PMOS は VDD の近く、NMOS は GND の近くに置くのか</summary>

NMOS は、ゲートが**ソースより**少なくともしきい値電圧だけ高いときにオンになります。ソースが GND にあれば、VDD のゲートで完全にオンになるので、NMOS は配線を 0 に引き下げるのが得意です。1 を通すのに使うと、導通するにつれてソースが VDD に向かって上がり、VDD よりしきい値一つ分低いところで自分でオフになってしまい、弱い 1 しか出せません。PMOS はその鏡写しで、1 を通すのは得意、0 を通すのは苦手です。だから CMOS ゲートでは、PMOS トランジスタを VDD と出力の間に、NMOS を出力と GND の間に置きます。このコースのシミュレータはスイッチを理想的なものとして扱いますが、レベルはこの現実の規則に従っています。

</details>

## シミュレータが見せるもの

エディタの配線はどれも、四つの値のどれかを運び、その値は常に配線の上に書かれています。

- **0** と **1**:配線が GND か VDD にしっかりつながっています。
- **Z**:配線が **[[フローティング|floating]]** です。どちらのレールにもつながっていません。電圧は何にでもなりうるので、実際の回路は誤動作します。
- **X**:値が不明か、衝突しています。たいていは **[[ショート|short-circuit]]**、つまりオンのスイッチが VDD を GND に直接つないでいるのが原因です。

正しく動くゲートは、どんな入力に対しても、出力に Z や X を出しません。

## 最初のゲート:NOT

NOT ゲート(**インバータ**)は、入力の逆を出力します。CMOS ゲートには必ず二つの半分があります。

- 出力を VDD につなぐ(1 にする)PMOS トランジスタの **[[プルアップ回路網|pull-up-network]]**。
- 出力を GND につなぐ(0 にする)NMOS トランジスタの **[[プルダウン回路網|pull-down-network]]**。

NOT では、どちらの回路網もトランジスタ一つだけで、二つのゲートはどちらも入力につながります。入力が 0 のとき、PMOS はオン、NMOS はオフなので、出力は 1 に引き上げられます。入力が 1 のときは、その逆です。

これが、CMOS が**相補的な**組を使う理由です。どんな入力に対しても、ちょうど一方の回路網だけがオンになります。出力は常に駆動され(フローティングにならない)、VDD が GND につながることはなく(ショートしない)、何も切り替わっていない間はほとんど電流が流れません。これが、1963 年にワンラスとサーが示した低い待機電力です[@cmos]。

## NAND

NAND(「not and」)は、両方の入力が 1 のときだけ 0 を出力します。まずプルダウン回路網から考えましょう。A **と** B がどちらも 1 のときだけ出力を GND につなぐべきなので、二つの NMOS トランジスタは**直列**に置きます。

プルアップ回路網は、ちょうどそれ以外の場合、つまり A が 0 **または** B が 0 のときにオンでなければなりません。ですから二つの PMOS トランジスタは**並列**に置きます。プルアップは常にプルダウンの鏡写しです。直列は並列に、並列は直列になります。

**[NAND を作る →](#/play/nand)**

## NOR

NOR(「not or」)は、両方の入力が 0 のときだけ 1 を出力します。鏡写しの規則を使えば自分で導けます。A **または** B が 1 なら出力は引き下げられるので、NMOS は並列に、PMOS は直列に置きます。

**[NOR を作る →](#/play/nor)**

## なぜ NAND が大事なのか

CMOS の一段は必ず**反転する**ことに気づいてください。入力の 1 は NMOS をオンにして出力を 0 の方へ引くことしかできません。だから自然なゲートは AND や OR ではなく、NOT、NAND、NOR なのです。

NAND には驚くべき性質があります。**[[万能ゲート|universal-gate]]** なのです。ほかのどんな論理関数も NAND だけで作れます。たとえば、NOT は二つの入力をつないだ NAND で、AND は NAND のあとに NOT を置いたものです。NOR も万能です。第 2 章からは、すべて(マルチプレクサ、加算器、ALU 全体)をこの章のゲートで作り、トランジスタには二度と触れません。

## 二つの定数

第 2 章からは、むき出しの VDD と GND のレールを置けなくなります。部品だけで作るのです。それでも、固定の 0 や 1 が必要な回路はあります(たとえば、加算器の最初の桁にはキャリーが入ってきません)。そこで、小さな部品を二つ今のうちに作ります。**Constant 0** と **Constant 1** です。どちらも電源レールを一本出力につないだだけですが、一度作れば、ほかと同じ部品になります。

## チェックの仕組み

どのレベルにも真理値表が表示されます。配線するにつれて表はその場で更新され、各行が、回路の出力が合っているかを示します。行をクリックすると、その入力がキャンバスに設定されます。

**チェック**を押すと、すべての行がテストされます。どこかが間違っていれば、どの行がなぜ失敗したかが表示されます。メッセージには、出力が間違っていたのか、フローティングだったのか、ショートしていたのかが書かれ、関係する部品の名前が挙がります。メッセージをクリックすると、その行に移り、関係する部品に印がつきます。すべての行が合格すると、ゲートが解放され、続くレベルのツールボックスに現れます。

あとで、すでに合格したゲートを変更すると、それを使って作ったものすべてが再チェックされます。変更で何かが壊れると、レベルマップがそれに「壊れている」と印をつけるので、どこを見ればよいかわかります。

## 作ったもの、学んだこと

**作ったもの:** NOT ゲート(トランジスタ 2 個)、NAND ゲート(4 個)、NOR ゲート(4 個)。それぞれを真理値表でテストしました。さらに定数 0 と 1。

**学んだこと:**

- 直列のスイッチは AND を、並列のスイッチは OR を計算する。
- NMOS はゲートが 1 のとき、PMOS はゲートが 0 のときにオンになる。
- CMOS ゲートには、互いに鏡写しになった PMOS のプルアップ回路網と NMOS のプルダウン回路網があり、どんな入力でもちょうど一方だけがオンになる。出力はフローティングにもショートにもならない。
- CMOS の一段は反転するので、自然なゲートは NOT、NAND、NOR である。
- NAND(と NOR)は万能である。ほかのどんな論理関数もそれで作れる。

**次へ:** 第 2 章では、トランジスタのことを考えるのをやめ、ゲートで作ります。AND、OR、XOR、マルチプレクサ、加算器、16 ビットのバスです。NAND と NOT から AND を作ったら、NAND の部品をダブルクリックして中をのぞき、自分のトランジスタが働くところを見てみましょう。

</aside>
