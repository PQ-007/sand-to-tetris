第 2 章で作った回路はどれも忘れてしまいます。出力は今の入力だけで決まり、入力を取り去れば答えは消えます。コンピュータは物事を覚えていなければなりません。計算中の数、実行中のプログラム、そしてそのプログラムのどこにいるか。この章では、その記憶を自分のゲートで作ります。まず 1 ビット、次に 16 ビット、そして何千ワードも。記憶する回路を **[[順序回路|sequential-circuit]]** と呼びます。

## 覚えているループ

仕掛けのすべてはこうです。NOR ゲートを二つ用意し、それぞれの出力をもう一方の入力に戻します。これが **[[フィードバック|feedback]]** です。回路の出力が自分自身の入力になるので、次に何をするかが、今何をしているかで決まります。

出力を q と q̄(「q バー」、常に q の逆)と呼びましょう。上のゲートは r と q̄ から q を作り、下のゲートは s と q から q̄ を作ります。

- **s**(セット)を 1 にします。NOR はどれかの入力が 1 なら 0 を出すので、q̄ は 0 になります。すると上のゲートは 0 を二つ受け取り、q = 1 を出します。
- s を 0 に戻します。何も変わりません。q = 1 が q̄ を 0 に保ち、q̄ = 0 が q を 1 に保ちます。外から何も駆動していないのに、回路は値を**保持**します。
- **r**(リセット)を 1 にすると、逆向きに同じことが起こります。q は 0 になり、0 のままです。

この回路が SR **[[ラッチ|latch]]** です。試してみましょう。

<latch-demo></latch-demo>

デモで二つのことに注目してください。セットやリセットをすると、変化がループを一周するのに 2 [[ゲート遅延|gate-delay]]かかります。そして s と r が両方 1 だと、q と q̄ は両方 0 になり、互いに逆という約束が破れます。両方を同じ瞬間に離すと、ゲートは永遠に追いかけ合います。だからラッチに s = r = 1 を与えてはいけないのです。

この考えはトランジスタより古いものです。1918 年 6 月、ウィリアム・エクルズと F・W・ジョーダンは、互いに結合した二本の[[真空管|vacuum-tube]]が、それを設定した信号が消えたあとも二つの状態のどちらかにとどまる回路の特許を出願しました。最初のフリップフロップ回路です。それはのちに Colossus や ENIAC のコンピュータに使われました[@eccles-jordan]。

## データ入力一つ:D ラッチ

セットとリセットの入力が別々なのは扱いにくいものです。たいていは「**この**ビットを覚えて」と言いたいのです。**D ラッチ**にはデータ入力 d とイネーブル入力 en があります。

- en が 1 の間、q は d に従います。
- en が 0 になると、q はその瞬間の d の値を保ちます。

SR ラッチの上に作ります。d が 1 **かつ** en が 1 のときにセットし、d が 0 **かつ** en が 1 のときにリセットします。en が 0 のときはどちらも起こらないので、ラッチは保持します。おまけに、s と r が両方 1 になることはありません。

**[D ラッチを作る →](#/play/dlatch)**

## クロックとフリップフロップ

D ラッチは、イネーブルされている間は**透過的**です。d の揺れがすべてそのまま通り抜けます。では、あるラッチの出力が次のラッチの入力になる、そんなラッチでできたコンピュータ全体を想像してください。1 回のイネーブルのパルスの間に、値がいくつものラッチを駆け抜けてしまうかもしれず、結果は各ゲートの正確な速さ次第になります。必要なのは、ある一瞬にだけ変わる記憶です。

<line-figure name="slow"></line-figure>

答えは **[[クロック|clock]]** です。コンピュータ全体で共有する一つの信号で、0、1、0、1 と何度も繰り返します。記憶が変わってよいのは **[[クロックエッジ|clock-edge]]**、つまりクロックが 0 から 1 に上がる瞬間だけです。エッジとエッジの間はすべてが静止し、その間の論理は次の値を求める時間を得ます。

**[[フリップフロップ|flip-flop]]** は、D ラッチを二つ並べてこれを実現します。

- 一つ目(**マスター**)はクロックが 0 の間開いているので、d に従います。
- 二つ目(**スレーブ**)はクロックが 1 の間開いているので、マスターを写します。

両方が開いている瞬間は一度もありません。クロックが上がると、マスターはエッジ直前の d の値で閉じ、スレーブがその値を q に渡します。そのあと d がどう変わってもかまいません。マスターはクロックが下がるまで閉じており、そのときにはスレーブが閉じています。NOT ゲート一つで、二つのラッチに逆のイネーブルを与えます。

フリップフロップを使うには規則が一つあります。d はエッジの**前**のひととき、安定していなければなりません。これが **[[セットアップ時間|setup-time]]** です。クロックと同じ瞬間に d を変えると、どちらの値が記憶されるかわかりません。この章のテストのステップでは、d が落ち着いた状態で、クロックだけを単独で変えます。

**[D フリップフロップを作る →](#/play/dff)**

## 電源投入時は不明

メモリのレベルを開くと、出力は **X** と表示されます。これはバグではありません。実際のメモリも、電源が入ると各ラッチはどちらかに倒れ、それがどちらかは誰にもわかりません。シミュレータはそれを正直に示します。何かが記憶されるまで、値は不明です。テストのステップでは、期待値の列の `-`(「任意」と表示)は、そのステップではどの値でもよいことを意味します。

## レジスタ

フリップフロップは、立ち上がりエッジのたびに**毎回**何かを記憶します。たいていは、いつ記憶するかを選びたいものです。**Bit** は load 入力を加えます。エッジのたびに、load が 1 なら d を記憶し、そうでなければ自分の出力をもう一度記憶するので、値を保ちます。この選択は[[マルチプレクサ|multiplexer]]が行います。入力は q(保持)と d(読み込み)で、load がそのどちらかを選びます。

Bit を 16 個並べ、load とクロックを共有させると、16 ビットの **[[レジスタ|register]]** になります。一つの数を保持します。CPU は作業中の値をレジスタに置きます。

**[Bit を作る →](#/play/bit)** · **[Register →](#/play/register)**

## 時間を見る:波形

記憶は時間にかかわるものですが、真理値表には時間が表れません。メモリのレベルではどれも、エディタがキャンバスの下に **[[波形|waveform]]** を表示します。信号ごとに 1 行で、時間は左から右へ進みます。1 ビットの信号は矩形波で、数はラベル付きの区間で、不明な値は斜線の X のブロックで描かれます。

**テストのステップ**の表示ではレベルのテスト全体が見え、列をクリックするとその時点までテストを再生します。**ライブ**の表示はあなたの操作を記録します。d を切り替え、**clk を刻む**を押して、q が立ち上がりエッジでだけ変わるのを見てください。

## RAM:アドレス付きのメモリ

レジスタは一つの数を保持します。たくさん保持するには、**どれ**かを指定する手段、つまり家の番地のような **[[アドレス|address]]** が必要です。**[[RAM|ram]]**(ランダムアクセスメモリ)はレジスタの集まりで、どのアドレスも、ほかと同じ速さで読み書きできます。

<line-figure name="cabinet"></line-figure>

RAM8 は 16 ビットのレジスタを八つ保持するので、アドレスは 3 ビット(0 から 7)です。二つの仕事が必要です。

- **書き込み:** load は、そのアドレスのレジスタにだけ届かなければなりません。[[デマルチプレクサ|demultiplexer]]がまさにそれをします。8 出力のデマルチプレクサは、3 ビットの数で選んだ八つの出力の一つへ入力を送ります。
- **読み出し:** q は、そのアドレスのレジスタを示さなければなりません。8 入力のマルチプレクサが、八つの 16 ビットの数から一つを選びます。

どのレジスタにも同じ d と同じクロックが入ります。4 出力と 8 出力のデマルチプレクサ、8 入力のマルチプレクサを先に作ります。これらは第 2 章の組み合わせ回路の仲間です。

**[4 出力 DMUX →](#/play/dmux4way)** · **[8 出力 DMUX →](#/play/dmux8way)** · **[8 入力 MUX16 →](#/play/mux8way16)** · **[RAM8 →](#/play/ram8)**

もっと大きなメモリも同じ考え方の繰り返しです。RAM64 は RAM8 が八つです。6 ビットのアドレスは二つに分かれます。上位 3 ビットがどの RAM8 かを選び、下位 3 ビットがその中のアドレスです。RAM512 は RAM64 が八つ、RAM4K は RAM512 が八つで、12 ビットのアドレスで 4,096 ワードを指します。どの段階も、アドレスが広がっただけの同じ回路です。

**[RAM64 →](#/play/ram64)** · **[RAM512 →](#/play/ram512)** · **[RAM4K →](#/play/ram4k)**

<summary>さらに詳しく:あなたのメモリは何ゲートか</summary>

シミュレータで数えると、すべて自分のゲートで作った場合、フリップフロップは 15 ゲート、Bit は 23、Register は 368 です。RAM8 は八つのレジスタにアドレスの論理を加えて約 3,900 ゲート。大きな RAM はどれも一つ下の RAM 八つに、アドレス用の約 900 ゲートを足したものなので、RAM64 は約 32,000 ゲート、RAM4K は約 200 万ゲートになります。だからエディタは大きなメモリに高速モデルを勧めるのです。RAM4K のすべてのゲートをクロックのたびにシミュレートしていたら、時間がかかりすぎます。

## 実際のメモリ

実際のコンピュータが、いつもラッチでメモリを作ってきたわけではありません。1950 年代半ばから 1970 年代まで、ほとんどは **[[磁気コアメモリ|magnetic-core-memory]]** を使っていました。配線の格子に通した小さな磁性体のリングで、各リングは磁化の向きで 1 ビットを記憶し、電源を切ってもそれを保ちました[@core-memory]。1947 年から 1951 年の間に、何人もの発明者がこの考えの特許を出願しました。MIT の Whirlwind コンピュータが、1953 年 8 月に 32 × 32 = 1,024 個のコアの格子で初めて動かしてみせました。功績が誰にあるのかは、いまも議論されています[@core-memory]。

チップ上のメモリには 2 種類あります。

- **[[SRAM|sram]]**(スタティック RAM)は、各ビットをラッチ(ふつうはトランジスタ 6 個)に記憶します。電源がある限り値を保持します。ここで作る RAM と同じく、速いですが 1 ビットあたりの面積が大きくなります。
- **[[DRAM|dram]]**(ダイナミック RAM)は、各ビットを小さな **[[コンデンサ|capacitor]]** の電荷として記憶し、トランジスタ一つがそれを守ります。1 ビットあたりはずっと小さいのですが、電荷が漏れていくので、すべてのビットを 1 秒間に何千回も読んで書き直さ(**リフレッシュ**し)なければなりません。

IBM のロバート・デナードが 1 トランジスタの DRAM セルを考案し、その特許は 1968 年に認められました。IBM は当初、より危険の少ないと考えたスタティックメモリを代わりに出荷しました[@dennard-dram]。1970 年 10 月、インテルが 1103 を発表しました。買うことのできた最初の DRAM チップで、1,024 ビット、1 ビットあたりトランジスタ 3 個です。それはすぐに多くのコンピュータでコアメモリに取って代わりました[@intel-1103]。あなたが今これを読んでいるコンピュータの主記憶も DRAM で、デナードのセルの子孫です。

## プログラムカウンタ

CPU の中のレジスタの一つは特別です。**[[プログラムカウンタ|program-counter]]**(PC)は、次の命令のアドレスを保持します。クロックが刻むたびに、次の四つのうち一つを、この優先順位で行います。

1. **reset**:0 に戻る(プログラムを最初から始める)。
2. **load**:d のアドレスへジャンプする。
3. **inc**:1 つ数を増やし、次の命令へ進む。
4. それ以外:その場にとどまる。

エッジのたびに読み込むレジスタと、何を読み込むかを選ぶ三つの 16 ビットマルチプレクサの鎖で作ります。q か q + 1(INC16 から)、次に d、次に 0 です。マルチプレクサの鎖では最後のものが決めるので、reset はレジスタの直前、いちばん最後に置きます。

## メモリの高速モデル

第 2 章の高速モデルは、入力から答えを計算するものでした。メモリの高速モデルは、さらに**記憶**しなければなりません。高速な RAM8 は、クロックの合間も自分の八つのワードを保持します。一致チェックも違います。出力が過去に左右されるので、試すべき入力の一覧というものがありません。そこでシミュレータは、あなたの設計とモデルを並べて、電源投入から 10,000 回のランダムなクロックサイクルを走らせ、モデルが値を知っているときはいつも出力を比べます。RAM64 を作る前に RAM8 を高速モデルに切り替えると、回路は約 32,000 ゲートから 1,000 ゲート未満に減ります。**チェック**を押すと、すでに合格したメモリ部品はどのみち高速モデルとして動きます(どれも合格したときにモデルと比べられています)。切り替えで決まるのは、エディタでライブに動くものです。

## 作ったもの、学んだこと

**作ったもの:** 二つの NOR ゲートから SR ラッチ。D ラッチ。二つのラッチから D フリップフロップ。Bit と 16 ビットの Register。4 出力と 8 出力のデマルチプレクサ、8 入力の 16 ビットマルチプレクサ。RAM8、RAM64、RAM512、RAM4K。そしてプログラムカウンタ。

**学んだこと:**

- フィードバックで回路は記憶できる。互いに入力し合う二つのゲートが 1 ビットを保持する。
- ラッチはイネーブルの間は透過的で、フリップフロップはクロックエッジでだけ変わる。それによってコンピュータ全体が足並みをそろえて動ける。
- フリップフロップの入力は、エッジの直前に安定していなければならない(セットアップ時間)。
- メモリは電源投入時には不明で、何かが記憶されるまで不明のままである。
- レジスタはフリップフロップに読み込みの選択を加えたもの、RAM はレジスタにアドレスを加えたもので、書き込みにはデマルチプレクサ、読み出しにはマルチプレクサを使う。
- 大きな RAM は、アドレスを広げて同じパターンを繰り返す。
- 実際のメモリは、磁気コア、SRAM(ラッチ)、DRAM(コンデンサの電荷、絶えずリフレッシュ)と移り変わってきた。
- プログラムカウンタは次の命令のアドレスを保持する。reset、次に load、次にカウント。

**次へ:** 第 4 章では、コンピュータの命令を一緒に設計し、ALU、レジスタ、プログラムカウンタから CPU を作ります。
